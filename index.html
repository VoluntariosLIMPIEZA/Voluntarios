Conectar Supabase
  1. Crea un proyecto en supabase.com.
  2. Abre SQL Editor, pega el contenido de sql/schema.sql y pulsa Run.
  3. En Project Settings → API copia la Project URL y la clave anon public.
  4. Pégalas aquí (quedan en este dispositivo) o en js/supabase-config.js antes de publicar.
